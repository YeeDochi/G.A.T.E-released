# G.A.T.E

Game-master Agent Tabletop Environment — 친구들과 TRPG를 할 때 호스트 PC에서 여는 앱입니다. AI 키퍼, 탁 서버, 친구 접속 주소(터널)를 한 번에 열고 닫습니다.

이 저장소에는 설치 파일만 올라옵니다.

## 설치

1. [Releases](../../releases/latest)에서 `GATE-Setup-<버전>.exe`를 받습니다.
2. 실행하면 바로 설치되고 앱이 열립니다. 아직 코드 서명이 없어 Windows가 경고하면 "추가 정보" → "실행"을 누릅니다.
3. 처음 열면 상태 창에서 관리자 계정과 AI 키퍼 엔진(Claude Code 또는 OpenRouter 키)을 정합니다.

- Windows 10/11 64비트
- 새 버전은 앱이 알아서 받아 두고, 종료할 때 설치합니다.
- 지우기: Windows 설정 → 앱 → 설치된 앱 → "G.A.T.E". 탁 데이터(`%LOCALAPPDATA%\GATE`)는 남습니다.

## 고지

이 앱으로 플레이할 수 있는 각 TRPG 룰셋의 이름과 상표는 각 권리자의 것이며, 이 프로젝트는 그 권리자들과 무관한 비공식 프로젝트입니다.
